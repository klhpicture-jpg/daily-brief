Introducing GPT-6 Sol and Luna

OpenAI News · 1 t siden

OpenAI udvider GPT-6 med Sol og Luna, trænet med samme metode som Astra, men til markant lavere pris og hurtigere inferens. Konteksten er pres på omkostninger fra længerevarende agent-arbejde, hvor token-forbrug eksploderer. Ny caching giver 90% rabat på genbrugte prompt-reads, og Sol/Luna slår eller matcher Claude Fable/Opus på flere agent-, kode- og computer-use benchmarks til 60 til 96% lavere pris pr. opgave. Det ændrer kalkylen for agentbaserede workflows, hvor pris per langvarig opgave er vigtigere end pris per prompt.

How will AI change operating systems? Part 2: Windows

The Pragmatic Engineer · Gergely Orosz · 2 t siden

The Pragmatic Engineer beskriver Microsofts plan for Windows: indbygget agent-identitet via Entra ID, et lokalt On Device Agent Registry for MCP-værter og Defender, der bliver agent-aware. Konteksten er udviklere, der har forladt Windows, mens macOS og Linux trækker fra. Nu satser Windows på lokale modeller via WindowsML på GPU, NPU og CPU, WSL som first-class og opinionated biblioteker til at bygge agenter. Det kan bringe devs tilbage og standardisere agent-sikkerhed og værktøjsadgang på OS-niveau.

llm-typesafe 0.1a0

Simon Willison · 3 t siden

Simon Willison udgiver llm-typesafe 0.1a0, et plugin til hans LLM CLI, der tilføjer TypeSafe AI’s Jev-model. Konteksten er behovet for typerent output fra modeller, så evals og ruter kan automatiseres uden skøre parse-failures. Plugin’et gør det let at stille ja/nej-spørgsmål med sandsynlighed, valg mellem kategorier eller scoring mod faste kriterier direkte fra terminalen. Det ændrer ikke verden, men sænker friktionen for operationelle evals og regel-baserede beslutninger i pipelines.
